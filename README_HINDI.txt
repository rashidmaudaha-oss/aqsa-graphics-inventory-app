AQSA GRAPHICS INVENTORY SYSTEM - ANDROID PROJECT

Yeh Android Studio project hai, compiled APK nahi. Is environment mein Android SDK/Gradle build tools maujood nahi hain, isliye APK binary yahan compile nahi ki ja sakti.

APK banane ka tareeqa:
1. Android Studio install/open karein.
2. File > Open se is ZIP ko extract karke folder select karein.
3. Gradle sync complete hone dein.
4. Build > Build Bundle(s) / APK(s) > Build APK(s) select karein.
5. APK app/build/outputs/apk/debug/app-debug.apk mein milegi.
6. Phone mein APK bhejkar install karein. Zarurat par Android Settings mein "Install unknown apps" allow karein.

App URL: https://inv.aqsagraphics.com/
App name: AQSA GRAPHICS INVENTORY SYSTEM

Note:
- App internet connection ke saath chalegi.
- Login aur data aapke existing web app/Google Apps Script par hi rahenge.
- Pehle phone par URL Chrome mein test karein; phir APK install karke login, Quick Search, Stock In/Out aur PO/Returns test karein.
